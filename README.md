# Море красок — студия красоты в Екатеринбурге

Одностраничный сайт мастера красоты Анастасии (Богдашова Анастасия Викторовна).

**Сайт:** https://more-krasok.ru (хостинг — Vercel)

## Что на сайте

- Услуги и цены (маникюр, педикюр, стрижки, окрашивание, завивка, брови)
- Визуальный календарь рабочих дней мастера
- Контакты: телефон, Telegram, WhatsApp, адрес с картой
- SEO: schema.org BeautySalon, Open Graph, sitemap, Яндекс.Метрика

## Структура

```
├── index.html       # Вся страница
├── css/styles.css   # Стили
├── js/main-v2.js    # Календарь графика работы
├── images/          # Фото (WebP)
├── vercel.json      # Заголовки кэширования
├── robots.txt / sitemap.xml
```

## Как обновить график работы

В `js/main-v2.js` есть массив `WORK_DAYS` — список рабочих дней в формате `'YYYY-MM-DD'`.
Дни, которых нет в списке, показываются как выходные. Сейчас график заполнен до конца августа 2026 —
в конце лета нужно добавить сентябрь и далее.

## Как обновить фото

Положить новое фото в `images/` (лучше WebP шириной ~800px) и поменять `src` в `index.html`.

## Деплой

Пуш в `main` — Vercel деплоит автоматически.
