# Море красок — студия красоты в Екатеринбурге

Одностраничный сайт мастера красоты Анастасии (Богдашова Анастасия Викторовна).
Уралмаш, ул. Донбасская, 4.

**Сайт:** https://more-krasok.ru

## Как это устроено

Весь сайт — **один файл `index.html`**: разметка, стили в `<style>`, скрипты в `<script>`.
Никакой сборки, зависимостей и npm. Открыл файл, поправил, запушил.

```
├── index.html              # весь сайт целиком
├── redesign/index.html     # концепт нового дизайна (noindex, не в проде)
├── images/                 # фото, логотип, SVG-иконки услуг
├── favicon.svg
├── CNAME                   # привязка домена more-krasok.ru
├── robots.txt / sitemap.xml
└── .github/workflows/pages.yml   # автодеплой
```

## Деплой

Пуш в `main` → GitHub Actions публикует корень репозитория на GitHub Pages → https://more-krasok.ru.
Занимает около минуты. Отдельной команды деплоя нет.

Раньше сайт жил на Vercel, но его заблокировали в РФ — переехали на Pages 03.07.2026.

## Как обновить график работы

⚠️ **Это самое частое и самое важное обновление.**

График живёт в приложении **«Lubava: Запись клиентов»** — там мастер отмечает **жёлтым выходные**
(зелёным подсвечиваются дни, где уже есть запись, — это тоже рабочие дни).

Сайт хранит данные так же, чтобы перенос был копированием один в один. В `index.html`
в конце файла:

```js
var OFF_BY_MONTH={
  '2026-12':[4,5,8,9,13,14,18,19,22,23,26,29],   // жёлтые числа из «Lubava»
  ...
};
```

Добавить месяц = добавить строчку. Всё, что не выходной, — рабочий день.
Месяц считается опубликованным просто потому, что он есть в списке.

Месяц, которого в списке нет, календарь не красит в сплошные выходные, а пишет
«график ещё не опубликован» — так клиент видит, что нужно написать, а не что мастер не работает.

График **нерегулярный**: обычно выходные идут парами с промежутком 4–5 дней, но правило
регулярно нарушается — в декабре, например, 26 и 29 стоят поодиночке. Формулы за этим нет,
вычислить даты нельзя — только переносить руками. Держать заполненным минимум на 2 месяца вперёд.

## Как добавить или изменить услугу

Там же, массив `SERVICES` — карточки услуг рисуются из него в цикле.
Поля: `ic` — имя SVG-иконки из `images/` без расширения, `n` — название,
`d` — описание, `t` — длительность, `p` — цена, `req:true` — цена «по запросу».

## Как обновить фото

Положить файл в `images/` (лучше WebP шириной ~800px) и поменять `src` в `index.html`.
