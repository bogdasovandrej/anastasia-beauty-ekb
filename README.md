# Море красок — студия красоты в Екатеринбурге

Одностраничный сайт мастера красоты Анастасии (Богдашова Анастасия Викторовна).
Уралмаш, ул. Донбасская, 4.

**Сайт:** https://more-krasok.ru

## Как это устроено

Весь сайт — **один файл `index.html`**: разметка, стили в `<style>`, скрипты в `<script>`.
Никакой сборки, зависимостей и npm. Открыл файл, поправил, запушил.

```
├── index.html              # весь сайт целиком
├── redesign/index.html     # концепт нового дизайна (noindex, не в проде)
├── images/                 # фото, логотип, SVG-иконки услуг
├── favicon.svg
├── CNAME                   # привязка домена more-krasok.ru
├── robots.txt / sitemap.xml
└── .github/workflows/pages.yml   # автодеплой
```

## Деплой

Пуш в `main` → GitHub Actions публикует корень репозитория на GitHub Pages → https://more-krasok.ru.
Занимает около минуты. Отдельной команды деплоя нет.

Раньше сайт жил на Vercel, но его заблокировали в РФ — переехали на Pages 03.07.2026.

## Как обновить график работы

⚠️ **Это самое частое и самое важное обновление.**

**Мастер делает это сама, из мессенджера — трогать код не нужно.**

В боте под полем ввода есть постоянные кнопки, печатать ничего не надо:

| Кнопка | Что делает |
|---|---|
| ✍️ Записать клиента | Записать того, кто позвонил напрямую: день → услуга → время → имя и телефон |
| 📋 Мои записи | Кто и когда придёт, с телефонами и пометками |
| 📅 График | Отметить выходные |
| 📓 Блокнот | Фамилии и всё, что нужно не забыть |
| 📱 Календарь на телефон | Ссылка для подписки — записи сами появятся в календаре телефона |

Заметки: ответ на уведомление о записи прицепляется к этой записи, любой другой
текст уходит в блокнот. Команды `/grafik`, `/zapisi`, `/zametki` тоже работают.

Записи хранятся полгода, заметки — год, потом удаляются сами (ежедневная задача
в 3:00 UTC). Персональные данные не должны копиться годами.

Пошаговая запись клиента пока есть только в Telegram: в МАКСе кнопка подсказывает
перейти туда. График, записи и блокнот работают в обоих.

### Календарь вручную

Пишет боту `/grafik` (Telegram или МАКС), листает месяцы стрелками и нажимает на числа.
Выходные помечаются точками: `·11·`. Каждое нажатие сохраняется сразу, кнопки «Сохранить»
нет намеренно — нечего забыть нажать.

Новый месяц сначала надо открыть средней кнопкой внизу (`⛔ месяц закрыт` → `✅ месяц открыт`),
и только потом отмечать в нём выходные.

График хранится в базе D1 и отдаётся сайту по адресу `/schedule.json`. Страница забирает его
при загрузке — правка в боте видна на сайте почти сразу.

### Запасной график в коде

В `index.html` лежит `OFF_BY_MONTH` — копия расписания, зашитая в страницу:

```js
var OFF_BY_MONTH={
  '2026-12':[4,5,8,9,13,14,18,19,22,23,26,29],
  ...
};
```

Он используется, только если сервер не ответил, чтобы посетитель не увидел пустой календарь.
Обновлять его руками не нужно — но если расходится с реальностью слишком сильно, стоит
подтянуть, иначе при сбое сайт покажет устаревшее расписание.

Всё, что не выходной в открытом месяце, — рабочий день. Месяц, которого нет в графике,
календарь не красит в сплошные выходные, а пишет «график ещё не опубликован» — так клиент
видит, что нужно написать, а не что мастер не работает.

Исходно график берётся из приложения **«Lubava: Запись клиентов»**, где мастер отмечает
**жёлтым выходные** (зелёным — дни, где уже есть запись, они тоже рабочие).

Месяц, которого в списке нет, календарь не красит в сплошные выходные, а пишет
«график ещё не опубликован» — так клиент видит, что нужно написать, а не что мастер не работает.

График **нерегулярный**: обычно выходные идут парами с промежутком 4–5 дней, но правило
регулярно нарушается — в декабре, например, 26 и 29 стоят поодиночке. Формулы за этим нет,
вычислить даты нельзя — только переносить руками. Держать заполненным минимум на 2 месяца вперёд.

## Как добавить или изменить услугу

Там же, массив `SERVICES` — карточки услуг рисуются из него в цикле.
Поля: `ic` — имя SVG-иконки из `images/` без расширения, `n` — название,
`d` — описание, `t` — длительность, `p` — цена, `req:true` — цена «по запросу».

## Как обновить фото

Положить файл в `images/` (лучше WebP шириной ~800px) и поменять `src` в `index.html`.
