# Уведомление в Роскомнадзор — что вписывать

Подаёт **Богдашова Анастасия Викторовна** лично, со своей подтверждённой
учётной записи на Госуслугах. Бесплатно, один раз.

**Подавать после переноса базы в Россию** — иначе в графе о месте хранения
придётся указать зарубежный сервер.

---

## Как подать

1. Зайти на **gosuslugi.ru** под своей учётной записью (подтверждённой)
2. В поиске набрать **«Уведомление об обработке персональных данных»**
3. Выбрать услугу Роскомнадзора, нажать «Начать»
4. Заполнить поля значениями ниже
5. Отправить. Ответ приходит в личный кабинет, обычно за несколько дней

Можно и напрямую на **pd.rkn.gov.ru**, но через Госуслуги проще: часть полей
подставится сама.

```
Запись клиентов на услуги студии красоты, подтверждение записи
и связь с клиентом по поводу его записи.
```

### Правовое основание

```
Согласие субъекта персональных данных, полученное при оформлении записи
на сайте more-krasok.ru или через чат-бот. Статья 6 часть 1 пункт 1
Федерального закона № 152-ФЗ.
```

### Категории субъектов

```
Клиенты, записавшиеся на услуги.
```

### Категории персональных данных

```
Имя (как обращаться), номер телефона, выбранная услуга, дата и время записи.
Специальные и биометрические категории персональных данных не обрабатываются.
```

### Перечень действий

```
Сбор, запись, систематизация, накопление, хранение, уточнение (обновление,
изменение), извлечение, использование, удаление, уничтожение.
Обработка смешанная: с использованием средств автоматизации.
```

### Срок обработки

```
До достижения цели обработки или до отзыва согласия субъектом.
Записи с персональными данными удаляются автоматически через 6 месяцев
после даты визита.
```

```
Российская Федерация. Хранение осуществляется в Yandex Cloud
(Object Storage, регион ru-central1).
```

### Трансграничная передача

**Да.** Указать так:

```
Осуществляется передача в Федеративную Республику Германия и иные страны
размещения серверов мессенджера Telegram (Telegram Messenger Inc.) —
исключительно для доставки уведомления о новой записи самому оператору
на его личный аккаунт. Хранение персональных данных на зарубежных
серверах не осуществляется, база данных локализована в России.
```

Если решите отказаться от Telegram и оставить только МАКС — тогда
трансграничной передачи нет, и в этой графе ставится «не осуществляется».

## После подачи

- Оператор попадает в **реестр операторов** на сайте РКН — это нормально и публично
- Если что-то изменится (цели, категории данных, адрес) — подать уведомление
  об изменениях в течение 15 рабочих дней
- Политика на сайте должна соответствовать тому, что указано в уведомлении.
  Наша — соответствует: те же данные, те же сроки, тот же способ отзыва

## Чего это не отменяет

Уведомление — не разрешение и не проверка. Оно лишь ставит оператора на учёт.
Обязанности по защите данных остаются, и именно поэтому мы переносим базу
в Россию до подачи, а не после.
