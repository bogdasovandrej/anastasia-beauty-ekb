# Переезд с reg.ru на бесплатный хостинг

> Хостинг reg.ru (Host-0, u3500332) оплачен до **29.06.2026**, стоимость ~600 ₽/год.  
> Рекомендуется переехать **до** этой даты на бесплатный хостинг.

---

## Рекомендуемый вариант: Cloudflare Pages

**Почему Cloudflare Pages:**
- ✅ Бесплатно навсегда (статичные сайты)
- ✅ Автоматический деплой при каждом пуше в GitHub
- ✅ CDN по всему миру (быстрая загрузка)
- ✅ HTTPS из коробки
- ✅ Поддержка собственного домена (бесплатно)

---

## Шаги

### 1. Зайти на Cloudflare Pages

Открыть: https://pages.cloudflare.com  
Нажать **Sign up** (или войти, если уже есть аккаунт).

### 2. Создать новый проект

1. Dashboard → **Workers & Pages** → **Create** → **Pages**
2. Выбрать **Connect to Git**
3. Выбрать репозиторий `bogdasovandrej/anastasia-beauty-ekb`

### 3. Настройки сборки

| Параметр | Значение |
|---|---|
| Project name | `anastasia-beauty-ekb` (или любое другое) |
| Production branch | `main` |
| Build command | *(оставить пустым — это статичный сайт)* |
| Build output directory | `/` *(корень репозитория)* |

Нажать **Save and Deploy**.

### 4. Получить URL

После деплоя Cloudflare выдаст URL вида:  
`https://anastasia-beauty-ekb.pages.dev`

Сайт уже работает!

### 5. Подключить свой домен (если есть)

Если есть домен `anastasia-beauty-ekb.ru` (или другой):

1. В Cloudflare Pages → **Custom domains** → **Set up a custom domain**
2. Ввести домен
3. Cloudflare предложит добавить DNS-запись

**Вариант A — домен на reg.ru:**  
- Войти в reg.ru → DNS-управление доменом  
- Добавить CNAME-запись: `@` → `anastasia-beauty-ekb.pages.dev`

**Вариант B — перенести домен в Cloudflare (лучше, бесплатно):**  
- https://developers.cloudflare.com/registrar/get-started/transfer-domain-to-cloudflare/
- Перенос домена в Cloudflare Registrar = цена регистратора без наценки

### 6. Отключить хостинг на reg.ru

После того как сайт заработал на Cloudflare:
1. Войти в reg.ru → **Хостинг** → `u3500332`
2. Отключить автопродление (или удалить хостинг вручную до 29.06.2026)
3. Деньги за неиспользованный период могут быть возвращены — уточнить в поддержке reg.ru

После смены домена/хостинга:
- Обновить сайт в **Яндекс.Вебмастер** (Search Console) — указать новый URL
- В **Google Search Console** — подтвердить новый URL
- Коды верификации уже вшиты в `<head>` страницы — менять не нужно
